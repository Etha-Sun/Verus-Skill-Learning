## 启动方式

先启动本地 Qwen 服务：

```bash
QWEN_VLLM_PYTHON=/path/to/vllm/python \
QWEN3_8B_MODEL_PATH=/path/to/Qwen3-8B \
skillopt-verusage/scripts/launch_qwen3_8b_vllm.sh
```

四个独立测试条件：

```bash
skillopt-verusage/scripts/run_s2_fixed_test20.sh gpt
skillopt-verusage/scripts/run_s2_fixed_test20.sh deepseek
skillopt-verusage/scripts/run_s2_fixed_test20.sh glm
skillopt-verusage/scripts/run_s2_fixed_test20.sh qwen
```

GLM 运行前必须在本地忽略的 `.env` 中配置 `ZAI_API_KEY`。DeepSeek key 已
存在；GPT 不需要额外 API key；Qwen 使用 localhost token。

## 成功标准

- 四组各自产生 20 个唯一 test result。
- 无 test/reference 泄漏，无原始数据修改。
- 每个结果为 V2_TRACE 或正常预算耗尽的 V1_TRUNCATED；任何 V0 必须明确归因。
- 每组汇报 solved/20、Claude-failed solved/5、请求数、token、现金或 GPU 时间。
- 只做一次 held-out test，不根据 test 结果修改 skill 或重新选择配置。
