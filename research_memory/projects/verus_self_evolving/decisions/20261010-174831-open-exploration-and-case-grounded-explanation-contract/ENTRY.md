## Decision

The active subproject research brief is
[RESEARCH_BRIEF.md](../../../../../trace-experience-autoresearch/RESEARCH_BRIEF.md).
This supersedes the earlier choice of evidence-record/verifier segmentation as
an active default. That proposal remains historical candidate material, not the
new researcher's starting method. The broad aim is improving transferable use
of trace experience on VeruSAGE with success and token-cost objectives, while
allowing evidence-backed problem reframing.

Prepare a fresh context without conversation history, project ideas, historical
method proposals or learned memory in its opening packet. Start with the neutral
brief, task/data schema, training-only evidence and executable evaluation contract.
Freeze independent alternatives and predictions before exposing historical methods
as comparators. Existing evidence must be considered before dependent comparisons
and claims; delayed exposure is not permission to hide counterevidence.

The current parent has already read old ideas and is not an independent researcher.
A child folder alone cannot establish context isolation because root instructions
and memory may be inherited. Actual separate quest prompt/files/tool access and
memory boundaries need verification. This pass only writes the brief; no quest,
model request, runtime setting, service restart or filesystem relocation occurred.
Training traces also inherit collection-policy biases despite fresh context.

## Metrics and explanations

Track success/cost frontier under matched online budgets. Keep all failures and
timeouts; separately report learning, actor and research-controller token and
monetary costs, cache treatment, and explicit amortization volumes. Do not optimize
success-only averages or silently alter tasks. Stable claims need uncertainty and
paired task evidence, not favorable selected repeats.

Require hypothesis, competing explanation, predicted behavior and falsification
criteria per experiment. Interpret good, bad and null outcomes. Case coverage
includes observed gains, regressions, persistent failures and common-success cost
changes when present. Report selection rules/counts, trace/code/verifier evidence
and missing state. Distinguish association from supported mechanism and controlled
local intervention; a convincing narrative alone does not establish why it works.
Select small ablations or interventions when needed and budget them explicitly.
