# Independent local audit contract

User requests ONE reviewer to audit inference-time and card design, primarily
the full trace. Audit-only; no fixes, paid runs, card edits or sealed-test access.
Review existing method artifacts, not paper novelty/publication readiness.

1. Reviewer reads stitched/raw full trace and actual deployed card bodies before
   conclusions. Verify provenance/completeness and exact tool/edit/validation events.
2. Report observed defects separately from risks and missing evidence. Rank
   problems with source anchors, minimal fixes and acceptance criteria, preserving
   agent-controlled optional retrieval and immutable prior evidence.
3. Root checks serious findings against primary sources, records prioritized
   next steps, updates CURRENT and index, and hands off report. Follow-ups remain
   proposals, not authorization to execute. Local evidence fallback because
   dedicated review/memory/bash_exec APIs are absent.

Reviewer output: fresh external inference-card-review-20261007-lGqbOO/REVIEW.md,
findings.json and inspected-source hashes. Canonical compact note stays here.

zero overhead, index exposure with body reading, or read count with utility.
