## Question and prior evidence

Does a short within-family directory reduce unnecessary rule exposure enough to
offset another tool interaction and selection decision?

Previous validation20 comparison was flat repaired78 A versus grouped B:
13/20 versus 14/20 budgeted Verus+Lynette passes, but 13/20 each with V2 compliance.
Helper body reads occurred in 5/20 versus 9/20 episodes. The one additional B
success did not read a reference body. Costs were essentially similar after
normalization; one B provider call has incomplete usage. These observations are
not evidence that another retrieval layer will help.

Report V2 compliance separately, including compliant dual passes. Do not relabel

time, actual estimated billing, and common-rate normalized estimated billing.

than treating missing usage as zero. Include timeouts in all-task resources.
Use task-paired differences and the historical paired-bootstrap convention
(10,000 resamples, seed 20261006); n=20 and one repeat cannot establish tight
non-inferiority or generalization.

Mechanism: distinguish SKILL/file listings, reference-directory reads, rule-body
reads, full fallback reads and direct-file bypass. Record event count, unique
family/rule IDs, source cards actually delivered, returned content bytes, full
serialized tool-output bytes, and tool-call/round-trip counts. Tool output token
counts must use the same documented tokenizer/proxy if exact counts are unavailable.
A helper response is exposure, not proof of adoption or relevance. Reading part
of a file or searching it must not be labeled a full body read without evidence.

For C, report directory-to-body conversion and directory visits with no later
body read, including a later direct-file read in the same family. Report unchanged
single-rule families separately. A/B raw read-event counts are not equivalent
units; B returns several rules at once whereas C may return a directory only.
Primary effect estimates use all 20 pairs, not the post-treatment subset that read.

Expected interpretation: lower returned bytes alone is not success if the extra
round trip increases total tokens/cost or reduces solved tasks. This trial is
exploratory, not proof that every family should have a second retrieval layer.
