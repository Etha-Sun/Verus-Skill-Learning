# 原trace＋增广trace：optimizer视角的信息增量审计

**结论：如果目标是让optimizer从原trace之外获得更多有区别的经验，我会保留v1的核心样本，再从v2补互补案例，而不会因为v2省token就整体替换为v2。** 本次v1有一项更清楚的新增成功证明分解（AC CP5），v2没有相应新增成功模式；v2 AC CP3则提供有价值的失败对照。IR两版信息大体相同，AL两版大多重复原有经验。此为人工语义判断，不是实际SkillOpt训练结果或模型版本排名。

## 我如何模拟optimizer阅读

先读三条原trace的全部源码变化和最终F，再结合已完成的38条逐点语义审计，按“适用条件→动作→实际反馈→修复／失败边界”归类。只使用代码和工具证据，不把hint或actor自述当已证明知识。原始事件的编辑位置已另存原轨迹证据索引（未随本次发布的本地材料）。本次没有运行真正的optimizer，也没有测试学出的skill；这里评估可供学习的内容，不声称已经学到或可以泛化。

比较单位是**去重后的经验主题**，不是成功终点数、源码hash或token。一个trace可能含多个主题；多个trace也可能只有一个主题。以下主题数量只是当前明确粒度下的审计目录，不是信息论量，也不能相加除以19当“有效率”。

- **K：新增且有成功验证的策略／实现选择。** 与本题原trace相比，增加另一种可执行选择。
- **F：有具体诊断的失败边界。** 没有完成也可用，但不能把未证明合同作为知识。
- **E：新增局部错误—修复反例。** 有价值，通常比完整策略的适用范围窄。
- **B：原有原则的新表达或跨题实例。** 增加覆盖证据，不按新原则重复计数。
- **R：原经验重复／更紧凑复现。** 可作清楚的代表，不必全部同权放入batch。

## 如果现在交给我生成skill，我会怎样组织batch

先保留每题原trace作为基线，不把下面的代表清单解释为删除原始数据或停止保留其他实验。

1. **IR库复用对照：** 原手写见证＋v1 CP1（干净库路线），加v2 CP1的错误入口→方法修复短片段即可。其余同库定理成功只作稳定性／起点覆盖证据。若需严格同起点“库vs手写”对照，可改选CP3的两版；不必把所有代表再叠加。
2. **AC证明组织对照：** 原内联证明＋v1 CP5（专用helper成功）＋v1 CP3与v2 CP3（同起点局部修复成功vs泛型化未解）。这里能提炼“什么时候只缺上下文、什么时候拆状态见证、新增helper需要验证哪些合同”。不同CP间不能作成本因果比较。
3. **AC完整性失败：** v1 CP1与v2 CP1同起点成败对照，可补“主链义务清单不能被局部修复替代”。与前组F1部分重叠，预算紧时只保留未覆盖的主链缺口片段。
4. **AL逆向前提反例：** 原正确分解＋v1 CP1错误else及后续修复。v2 CP3或CP5可选一条作干净修复示范；不需要七个checkpoint重复传达长度／索引／导入这几条经验。

对真实optimizer仍需提供原题、起点全代码、必要依赖和真实诊断；此处“短片段”只指减少重复对话，不能裁掉判断一个动作所需的上下文。以失败修复为主题的样本可以保留失败，不把2条未解项当作成功，也不因为它们失败就剔除全部经验。

## 可以写进skill的候选规则与不该学的结论

- **可提炼：** 先核对已有定理合同；若状态已提供目标消息，直接复用该见证；对混合状态／时序证明可拆经验证的状态helper，再显式建立execution上的family实例；始终检查原目标及新helper合同是否全部闭合。
- **反例支持的约束：** 逆向蕴含需要逆向前提；不要靠新写ensures把尚未证明的结论变成可用事实；保持量词绑定对象一致；实际验证错误不能由actor自述“这只是分阶段展开”消除。
- **不可提炼：** 不要抽helper／泛型证明一定坏；库解法永远优于手写；v2一定更好；失败次数越多信息越多；Lynette通过意味着数学正确。

这些规则是基于本次材料的候选摘要，不是已部署skill。实际价值还需比较optimizer产出的规则是否正确、非重复、适用条件明确，并用独立题目测试。

## 两版的选择结论

**以增量信息广度优先：本次偏向v1，主要因为AC CP5的成功模块化和AL CP1的明确反例，而非因为它更长或犯错更多。以清楚紧凑的正例优先：AL v2更适合作代表，但它大多没有比原trace增加新数学内容。** IR两版几乎可互相替代；AC宜两版混合，尤其保留成功helper与失败泛型化对照。

因此最合理的当前结论不是“选一个版本的19条全部送入”，而是“按经验主题选代表，并把同起点成功／失败组织在一起”。这与老师的batch组织方向一致，但本次没有实施batch训练或curriculum，也没有证据确定最佳样本顺序。完整38条保留，新的信息主题与重复覆盖在训练输入中应显式标记。
