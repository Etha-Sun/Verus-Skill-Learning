# Qwen3.6 Three-Target Information-Gain Experiment Plan

**Problem**: 在相同 VeruSAGE trajectory states 和 matched controls 下，同时测量 artifact 对下一步修复 action、最小 proof patch、完整 final verified file 的信息增益，判断三个层级的信号是否一致。

**Method thesis**: 使用 Qwen3.6-27B 非 thinking teacher forcing，对同一 state/artifact matrix 计算 action、patch、full-proof 的 paired log-likelihood ratio；以 matched-control specific IG 区分 state-specific utility 与任意附加文本扰动。

**Date**: 2026-07-14

## Claim Map

| Claim | Why it matters | Minimum convincing evidence | Anti-claim |
|---|---|---|---|
| C1 cross-target artifact utility | Action proxy 不能替代 proof generation | Evidence 在 action、patch、full-proof 三个 target 上分别报告 raw IG 和 specific IG；至少能定位作用发生在哪一层 | 只在一个强制 action channel 中出现的变化被误称为 proof improvement |
| C2 measurement integrity | 长 target、prompt 和任意文本会制造假 IG | 非 thinking 官方模板、完整 action labels、exact-token controls、无未来泄漏、逐 token记录、长度/截断审计和断点恢复全部通过 | 结果来自 A-V 低概率字母、不同 token budget、截断或重复 baseline 计算 |

本轮 action target 是 trace 中 `observed locally accepted action`，不是全局最优 action。3 traces / 6 states 是机制探索，不支持 held-out 泛化或 downstream solved-rate claim。

## Paper Storyline

- Main paper must prove: 三个 target 层级的 IG 可以被统一、可审计地测量；relevant evidence 是否超过 matched null 必须逐 target 判断。
- Appendix can support: token/chunk curves、长度密度、action rank/entropy、失败 case。
- Intentionally cut: RL training、motif/TLA artifact、20-50 trace scaling、live agent injection；它们不阻塞本轮三指标测量。

## Experiment Blocks

### B1: Model And Target Audit

- Claim tested: C2。
- Dataset: 已冻结的 3 verified Claude hands-on traces / 6 locally accepted states。
- Model: official `Qwen/Qwen3.6-27B`, dense 27B, vLLM 0.19.1, TP=4, text-only, non-thinking chat template。
- Checks: model/tokenizer hash、all context+target token lengths、22 action ontology coverage、patch nonempty、full file SHA 与 verified source 一致。
- Action channel: assistant prefix `{"action":"`，target 为完整 action label 加 `"}`；禁止 A-V。
- Success: action channel 可评分，所有 targets 在模型 context 内；若超长，使用固定 left-context sliding teacher forcing，并显式标 approximate。
- Priority: MUST-RUN。

### B2: Action IG

- Claim tested: C1/C2。
- Compared conditions: shared no-artifact baseline；`evidence_artifact`；`cross_trace_same_error`；`cross_trace_any`；`block_shuffled`；`counterfactual_error`；`irrelevant_archive`；`empty_container` 仅作 wrapper diagnostic。
- Primary metric: raw full-label `IG_sum_bits` 与 `specific_IG_action`。
- Secondary: 22-label candidate-normalized PMI、rank、entropy、candidate sequence mass、IG/token。
- Success criterion: 完整报告，不作为 patch/full-proof stop gate；若 candidate mass 低，只降级 normalized metric，保留 raw full-label IG。
- Priority: MUST-RUN。

### B3: Patch IG

- Claim tested: C1。
- Target: deterministic proof-relevant minimal changed spans produced by the existing diff audit；保留 hunk metadata 和 source SHA。
- Metrics: token-level delta、`IG_sum_bits`、`IG_mean_bits_per_token`、hunk IG、specific IG、positive states、paired wins。
- Success criterion: 6 states × complete artifact matrix 全部评分；不得因 Action IG 正负停止。
- Failure interpretation: evidence 若不超过 null，说明当前 artifact 不提升局部 proof edits。
- Priority: MUST-RUN。

### B4: Full-Proof IG

- Claim tested: C1/C2。
- Target: 每个 state 对应的完整 final verified `.rs` 文件，不替换为 function-only target。
- Metrics: 每 token baseline/artifact probability 与 logprob、total/mean IG、固定 512-token chunk IG、cumulative IG、specific IG、长度密度。
- Execution: `tqdm` case/token progress bar，显示 completed cases、target tokens、elapsed/ETA；每 case flush checkpoint，支持 `--resume`。
- Truncation: 先尝试完整 teacher forcing；只有 tokenized context+target 超过模型上限时才启用固定 window sliding score，记录 window/overlap 和 exact/approximate flag。
- Success criterion: 6 states × complete artifact matrix 全部完成；昂贵不是停止理由。
- Priority: MUST-RUN。

### B5: Cross-Target Analysis

- Claim tested: C1。
- Outputs: 三指标 state-level paired table；evidence-vs-null；action/patch/proof Spearman；sign agreement；artifact rank stability；逐 chunk proof curves。
- Main figure: action、patch、full-proof specific IG 三面板；另附 irrelevant/evidence state comparison。
- Claim boundary: 只报告 artifact 对 demonstrator targets 的离线 likelihood effect，不声称 agent solved-rate improvement。
- Priority: MUST-RUN。

## Risks And Mitigations

- Qwen3.6 默认 thinking：使用官方 `enable_thinking=False` chat template，并测试 assistant boundary。
- Action channel 仍可能低 mass：改用完整 label/JSON prefix；raw full-label IG 始终保留。
- Full proof 超 context：token audit 后优先提高 max length；仅必要时 sliding，且 exact/approximate 分开报告。
- 长 run 中断：逐 case atomic checkpoint、`--resume`、稳定 case id、进度条和日志。
- Baseline 重复：按 `(state, target, prompt)` cache/持久化一次 baseline score，artifact rows 引用相同 baseline hash。
- Trace target 非 optimal：始终称 demonstrator target；不把 action likelihood 当最优策略。
