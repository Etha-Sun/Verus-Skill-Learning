# Corrected Action Information-Gain Pilot Results

## Verdict

R016/R017 demonstrate that local QwQ-32B can compute normalized action-distribution PMI reproducibly. They do **not** show that the current trace rationale or generic skill is uniquely useful. The predeclared artifact-quality gate failed, so patch/full-proof scoring and dataset scaling are deferred while remaining in the plan.

## Setup

- Data: 3 verified hands-on Claude traces, 7 early/middle/late states, read only.
- Scorer: local QwQ-32B, vLLM tensor parallel 4, chat generation boundary.
- R017 candidate set: 4 actions observed in the pilot manifest. This is now classified as an in-sample engineering pilot, not a final policy evaluation.
- Artifacts: empty container, generic skill, trace rationale, shuffled rationale, wrong-error rationale, word-count-matched neutral text, irrelevant text.
- Metric: `log2 P(observed action | state, artifact) - log2 P(observed action | state)` over a normalized candidate distribution.

## Audit Findings And Fixes

- PMI, entropy and normalization formulas independently recomputed correctly.
- One of seven logged target actions was not locally accepted. Labels are now named `observed_action`; v2 cases can filter to accepted actions.
- A fixed 22-action ontology is now frozen in `configs/verusage_action_ontology.txt`; v2 observed-action coverage is 100%, with zero OOV.
- Density now divides by exact chat-context token increase, including artifact wrapper overhead.
- The old neutral control is explicitly called word-count matched; it was not tokenizer matched.
- Paired state differences, paired summaries and trace-cluster bootstrap intervals are now generated by `ig-probe-analyze`.

## Next Experiment

Generate artifacts from actual trajectory evidence rather than fixed templates, then score the six accepted v2 states against randomized token-matched controls. Reopen patch/full-proof scoring only if the relevant artifact beats shuffled and irrelevant controls directionally under this corrected protocol.
