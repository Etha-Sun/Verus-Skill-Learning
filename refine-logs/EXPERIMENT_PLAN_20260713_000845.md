# Control-Null Action Information-Gain Experiment Plan

**Problem**: 判断 trajectory artifact 对 VeruSAGE action 的概率提升是否来自当前 proof state 的特异信息，而不是额外文本、长度、措辞或 option 位置效应。

**Method thesis**: 用决策前可见的 verifier evidence 构造 relevant artifact，并与逐 state、逐 tokenizer 精确匹配的多类破坏性 controls 比较；以 paired specific gain 而非 raw positive PMI 作为 gate。

**Date**: 2026-07-13

## Claim Map

| Claim | Minimum convincing pilot evidence | Anti-claim |
|---|---|---|
| C1 state-specific information | `evidence_artifact - mean(null controls)` 平均为正，至少 4/6 states 为正，并方向性超过每个主要 control family | 增长只来自 wrapper、长度、Verus 风格或 option 位置 |
| C2 measurement integrity | 所有 non-empty controls 与 evidence 的 exact chat intervention-token delta 相同；action ontology/OOV/provenance 固定且可审计 | scorer 在比较不同长度或 evaluation-derived action spaces |

本轮不声称 accepted action 是最优 action，也不声称 3 traces 可以代表 held-out 泛化。

## Experiment Blocks

### B1 Evidence Artifact

- 输入只能包含当前 prefix code、当前 verifier error、过去 action/error 和当前 score。
- 提取 error-local code window、proof markers、重复 error 次数、历史 action diversity 和 stagnation signal。
- 禁止读取当前 target action、当前 attempt 之后的 log 或 final verified proof。
- 目标：6 个 locally accepted observed actions。

### B2 Control Null

- `cross_trace_same_error`: 其他 trace 的 evidence，优先匹配相同 error type。
- `cross_trace_any`: 其他 trace 的 evidence，不要求 error type 相同。
- `block_shuffled`: 保留本 state evidence 的词汇/代码块，破坏结构顺序。
- `counterfactual_error`: 保留格式但替换 verifier diagnosis。
- `irrelevant_archive`: 与 proof repair 无关的档案管理文本。
- `empty_container`: 仅测 wrapper effect，不参与 token-matched null mean。
- 所有 non-empty artifacts/controls 只通过共同前缀截断，在 QwQ direct-chat template 下匹配 exact intervention-token count；禁止重复 padding。

### B3 Action Distribution

- 固定 22-action ontology，报告 coverage/OOV。
- 每个 state 用确定性 hash seed 随机排列 option-to-action mapping；同一 state 的所有 artifacts 使用相同 mapping。
- QwQ 原 chat template 自动进入 `<think>`，因此本实验使用显式 `chat_direct` assistant boundary，测量 reasoning-suppressed direct action classification proxy，不把它表述成完整 agent 最终决策分布。
- 保存 22 个 option 在 baseline/artifact 下的 token probability、logprob 和 normalized probability。

### B4 Metrics And Gate

- Raw diagnostic: decision PMI bits、observed-action probability/rank、entropy change。
- Primary: `specific_gain_s = PMI(evidence_s) - mean_c PMI(control_{s,c})`。
- Secondary: evidence-vs-control paired wins、null percentile、exact-intervention-token density。
- GO: mean specific gain > 0、positive states >= 4/6，且 evidence 对 `cross_trace_same_error`、`block_shuffled`、`irrelevant_archive` 各至少赢 4/6。
- STOP: gate 失败则不运行 patch/full-proof，不扩大 traces；先修改 artifact construction。
