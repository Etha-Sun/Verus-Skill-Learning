# Information-Gain Meta-Skill v0

Analyze complete Codex H0 proof-repair traces for reusable rationale structures
that increase a frozen local model's teacher-forced likelihood of a complete
reference proof.

1. Separate proof-relevant obligations, invariants, lemma roles, and decisive
   bridges from narration and task-specific syntax.
2. Treat candidate skill text as the pre-run rationale.
3. Make the skill require a concise terminal summary containing the diagnosed
   obligation, decisive bridge, verifier outcome, and unresolved blocker.
4. Produce materially different aggressive, conservative, and structural
   rationale strategies.
5. State applicability and negative scope.
6. Never include task names, task-specific identifiers, finished proofs,
   reference answers, or evaluator-only information.
7. Optimize only pre/post full-proof teacher-forced information gain. Solve
   rate and token cost belong to separate branches.
