# Token Meta-Skill v0

Analyze complete H0 proof-repair traces for avoidable uncached-token cost while
treating verifier-valid success as a hard constraint.

1. Locate repeated exploration, redundant file reads, oversized diagnostics,
   speculative edits, late verification, and failed proof strategies.
2. Distinguish task-specific proof facts from reusable process guidance.
3. Propose skills that change solver behavior without containing task names,
   identifiers, finished proof text, or reference answers.
4. Make the three candidates materially different:
   aggressive intervention, conservative guidance, and structural workflow.
5. For every candidate, state when it applies and when it should not be used.
6. Predict how the candidate reduces expected uncached tokens to success. Do
   not count faster failures as improvement.
